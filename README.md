# Customer Churn Workbench

A retention analytics dashboard with cohort comparisons, filters, triage scoring, and CSV export. The bundled sample is fictional and intentionally small.

## Run

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Read [method and limits](docs/METHOD.md) before applying the heuristic to business decisions.
